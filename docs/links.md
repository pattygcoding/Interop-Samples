# Showcase links

Every address on <https://interop.pattygcoding.com/> names one **pairing** - a host language and the guest it
drives - and each is a real link that can be bookmarked or shared. This file is
generated by `tools/generate_dashboard.py` in the same run that writes
`public/interop-data.js`, so it always matches the repository: **37 host languages**
and **88 pairings**.

- A pairing's address is `<host>-<guest>`, e.g. <https://interop.pattygcoding.com/c-elixir>.
- A host language's address resolves to the first pairing it offers - the guest
  that sorts first - so <https://interop.pattygcoding.com/cpp> opens <https://interop.pattygcoding.com/cpp-assembly-32bit>.
- Any pairing can show its README or its expected output by adding a tab:
  <https://interop.pattygcoding.com/c-elixir/docs>, <https://interop.pattygcoding.com/c-elixir/output>, or `?tab=docs`.
- The same pairings answer on a subdomain (`c-elixir.interop.pattygcoding.com`,
  `cpp.interop.pattygcoding.com`), which needs a wildcard `CNAME`.
